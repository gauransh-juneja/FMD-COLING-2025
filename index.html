Model Analysis & Insights

Best Performer: Logistic Regression

Despite being the simplest model, Logistic Regression achieved the highest accuracy (78.45%) and best overall performance. This suggests that:

  • TF-IDF features effectively capture financial misinformation patterns
  • The dataset may be linearly separable for this task
  • Complex models may be overfitting to the training data

BERT Underperformance

BERT showed moderate performance (68.90% accuracy), with room for improvement due to:

  • Limited training data (1,953 samples) for fine-tuning
  • Domain mismatch between pre-training and financial claims
  • Need for more sophisticated hyperparameter tuning

RNN Performance

RNN achieved good performance (72.30% accuracy) with:

  • Better sequential pattern recognition than BERT
  • Reasonable computational efficiency
  • Potential for improvement with better architecture

About This Project

This capstone project focuses on detecting misinformation in financial claims using state-of-the-art machine learning and deep learning models. We trained and compared three different approaches to identify the most effective method for financial misinformation detection.

COLING25-FMD Dataset

1,953 financial claims with True, False, and NEI labels

Advanced Preprocessing

Text cleaning, tokenization, lemmatization, and feature engineering

Comprehensive Evaluation

Accuracy, precision, recall, and F1-score metrics for model comparison

Dataset Statistics

892 False Claims
717 True Claims
344 NEI Claims

Technical Specifications

Detailed technical implementation and methodology

Model Architecture

Logistic Regression

  • TF-IDF vectorization (5,000 features)
  • L2 regularization
  • Max iterations: 1,000
  • Random state: 42

RNN (LSTM)

  • Embedding layer (128 dimensions)
  • Bidirectional LSTM (64 units)
  • Dropout (0.5)
  • Dense layers: 32 → 3

BERT

  • BERT-base-uncased
  • Sequence length: 100
  • Fine-tuning epochs: 10
  • Batch size: 16

Preprocessing Pipeline

Text Cleaning

  • Lowercase conversion
  • Special character removal
  • Extra whitespace normalization
  • Stopword removal

Feature Engineering

  • Lemmatization (WordNet)
  • Tokenization (Keras)
  • Sequence padding
  • TF-IDF vectorization

Data Split

  • Train: 80% (1,562 samples)
  • Test: 20% (391 samples)
  • Stratified sampling
  • Random state: 42

Computational Requirements

Hardware

  • CPU: Multi-core processor
  • RAM: 8GB minimum
  • GPU: Optional (for BERT)
  • Storage: 2GB free space

Software Stack

  • Python 3.8+
  • scikit-learn 1.0+
  • TensorFlow 2.x
  • Transformers 4.x

Performance

  • Training time: 2min - 3hrs
  • Inference: 1ms - 200ms
